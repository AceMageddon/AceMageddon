## Backend: team projects at Ca' Foscari

Both platforms were built twice, as a monolith and as microservices, to compare the two architectures.

**[ClashArena](https://github.com/Shhh09git/ClashArena)**, an esports tournament platform (team of 2)<br>
I built the identity and security layer (registration, login, JWT and role-based access control) in both builds. I also wrote the monolith, the identity service, the API gateway, the Kubernetes manifests, and the GitHub Actions workflow that runs unit tests and an end-to-end smoke test.<br>
`Python` `Flask` `SQLite` `Redis Streams` `Docker Compose` `Kubernetes`

**[GYM IT System](https://github.com/personnna/software-architecture)**, gym tournament management (team of 4)<br>
I built the auth-service: a Flask API with JWT, RBAC middleware, AES-256-GCM encryption of sensitive fields and an admin panel, with tests, Kubernetes manifests, C4 architecture docs and an OpenAPI spec.<br>
`Python` `Flask` `PostgreSQL 16` `RabbitMQ` `Docker` `Kubernetes` `GitHub Actions`
